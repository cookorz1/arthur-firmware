## 2026-10-23：rc.5 与旧固件对比

使用者反馈：刷入 **v1.5.0-rc.5** 后，USB 随身 WiFi 提供上游网络、亚瑟通过 Wi-Fi 向终端共享时，测速表现有所提升。以下数据依据使用者提供并标注新旧固件的测速记录整理。

| 项目 | 记录 |
| --- | --- |
| 使用路径 | 随身 WiFi → USB 网络共享 → 京东云亚瑟 → Wi-Fi 终端 |
| 新固件 | v1.5.0-rc.5，源码 `01e43e4a7ffaf9cd28389c317015b39444bd0047` |

| 采样 | 每组 3 次，全部计入平均，未剔除首轮或较低结果 |

### 完整结果

各组按截图中的记录先后排列，单位为 Mbps。

| 次数 | 旧固件 | rc.5 新固件 |
| --- | ---: | ---: |
| 1 | 383.56 | 355.93 |
| 2 | 378.94 | 455.64 |
| 3 | 360.40 | 465.70 |
| **平均** | **374.30** | **425.76** |
| 范围 | 360.40～383.56 | 355.93～465.70 |

以未四舍五入的算术平均值计算，新固件平均提升约 **13.7%**；新固件最高记录为 **465.70 Mbps**。新固件有一次低于旧固件的三次结果，表明本组测试仍存在波动，不能解读为每一次测速都更快。

### 结果范围

本次反馈支持 rc.5 在该设备与网络条件下，USB 上游经亚瑟 Wi-Fi 共享的整体测速表现有改善。rc.5 全新安装默认软件流量分载与 USB RPS，保留配置升级仍需结合实际设置判断；记录没有单独隔离各项设置的作用，不能把全部提升归因于 RPS 或无线驱动。

此次记录未提供 OpenClash 的启用状态、命中规则或节点路径，因此不能作为 OpenClash 代理吞吐的验证。移动网络、无线信号、终端与测速节点都可能影响结果；后续可补充相同条件下的更多轮次，以及重启、USB 重插和长时间使用情况。

## 与转发加速的关系

- 软件流量分载与 NSS 互斥，OpenClash 启用或核心仍运行时执行兼容保护。
- USB RPS 负责分散收包处理，OpenClash 运行时可以保留；NSS 转发运行或全局软件包分载接管时不重复叠加。
- 两项功能的状态分别显示在“网络 → 加速与内存”，可使用 `ubus call arthur performance` 查看。

数据属于使用者的实测反馈，尚不构成所有设备、网络条件或代理模式的性能保证。
